# Skills QAEF

Каталог содержит двадцать зафиксированных интерфейсов QAEF. Статус `Доступен` означает только наличие публичного определения skill; он не является evidence выполнения пользовательской задачи. Сейчас доступны `$qaef-map-framework` и `$qaef-coverage`, остальные интерфейсы имеют статус `Планируется`.

## Старт и контекст

| Skill | Статус | Результат |
|---|---|---|
| `$qaef-init` | Планируется | Фиксирует режим, задачу, scope, authority и начальный контракт. |
| [`$qaef-map-framework`](qaef-map-framework/SKILL.md) | Доступен | Создаёт доказанную карту существующего фреймворка до правки тестов. |
| `$qaef-context` | Планируется | Собирает минимальный context packet с provenance и `UNKNOWN`. |
| `$qaef-status` | Планируется | Показывает состояние контекста и одно обоснованное следующее действие. |

## Проектирование

| Skill | Статус | Результат |
|---|---|---|
| `$qaef-design-cases` | Планируется | Проектирует трассируемые тестовые сценарии и матрицу покрытия. |
| [`$qaef-coverage`](qaef-coverage/SKILL.md) | Доступен | Находит пробелы покрытия в подтверждённой границе задачи. |
| `$qaef-evaluate` | Планируется | Оценивает качество дизайна по rubric и контрпримерам. |
| `$qaef-present` | Планируется | Готовит русскоязычный материал для обсуждения решения с руководителем. |

## Написание тестов

| Skill | Статус | Результат |
|---|---|---|
| `$qaef-write-unit-tests` | Планируется | Пишет isolated unit tests в стеке целевого проекта. |
| `$qaef-write-contract-tests` | Планируется | Пишет schema и contract tests по подтверждённому контракту. |
| `$qaef-write-api-tests` | Планируется | Пишет API tests для публичного поведения. |
| `$qaef-write-integration-tests` | Планируется | Пишет integration tests на границах зависимостей. |
| `$qaef-write-ui-tests` | Планируется | Пишет UI component или end-to-end tests по задаче. |
| `$qaef-write-load-tests` | Планируется | Пишет load/performance profiles в выбранном проектом инструменте. |
| `$qaef-write-security-tests` | Планируется | Пишет security negative tests в границах разрешённого scope. |

## Качество и восстановление

| Skill | Статус | Результат |
|---|---|---|
| `$qaef-review-tests` | Планируется | Возвращает проверяемые находки с severity и предложенным исправлением. |
| `$qaef-debug-tests` | Планируется | Исследует причину сбоя по evidence, не подменяя диагноз догадкой. |
| `$qaef-triage` | Планируется | Классифицирует сбой и назначает следующий безопасный шаг. |
| `$qaef-gate` | Планируется | Сводит применимые evidence перед передачей на review. |

## Передача

| Skill | Статус | Результат |
|---|---|---|
| `$qaef-handoff` | Планируется | Передаёт изменения, evidence, статус и открытые риски следующему владельцу. |
