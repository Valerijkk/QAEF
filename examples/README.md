# Примеры QAEF

Этот каталог показывает, как контракты QAEF выглядят на вымышленных задачах. Все пути относительные и относятся только к условному целевому репозиторию. Примеры не содержат команд исполнения и не подтверждают поведение какой-либо реальной системы.

Во всех примерах:

- сохранённый тест или разрешённый test-support является результатом задачи на реализацию;
- факт, вывод и неизвестное не смешиваются;
- наблюдение о подготовленном артефакте отделено от статуса выполнения;
- если проверка не проводилась, статус выполнения остаётся `NOT_RUN`, а поведение — `UNKNOWN`.

## Как читать итог

`Артефакт подготовлен: да` — обычное наблюдение: в примере показаны заявленные сохраняемые пути и содержимое. Это не отдельный verdict. Для выполнения используются только канонические значения; `Статус выполнения: NOT_RUN` означает, что тест не исполнялся, а вывод о поведении системы остаётся `UNKNOWN`.
