# Парный пример: качество context packet при постоянной задаче

## Постоянная задача пары

Добавить в режиме `existing` unit-тест поведения `normalize_coupon("   ") -> None` и сохранить его в `tests/unit/test_coupon_normalization.py`, не меняя production-код.

Это та же задача, что в [промпте до уточнения](prompt-before.md) и [промпте после уточнения](prompt-after.md). Оба исполнителя получают одинаковые `task.objective`, `task.mode` и полномочия. Меняется только качество источников и подтверждённых сведений внутри context packet.

## Пакет A — форма полная, контекст недостаточен

### task

#### objective

Добавить в режиме `existing` unit-тест поведения `normalize_coupon("   ") -> None` и сохранить его в `tests/unit/test_coupon_normalization.py`, не меняя production-код.

#### mode

`existing`

### sources

| path | kind | freshness | provenance |
|---|---|---|---|
| `task-contract.md` | контракт задачи | текущая задача | решение владельца |
| `notes/coupon-idea.md` | заметка | `UNKNOWN` | происхождение не подтверждено |

### facts

- `task-contract.md` задаёт ожидаемое поведение, разрешает запись только в `tests/unit/test_coupon_normalization.py`, исключает production-код и не разрешает исполнение.
- В заметке встречаются слова «пробельный купон», но она не является контрактом продукта и не описывает интерфейс функции.
- Спецификация продукта, production source и текущий test-файл в пакет не включены.

### inferences

- Для выполнения задачи потребуется unit-сценарий в названном существующем файле.
- Из имеющихся источников нельзя безопасно вывести import, сигнатуру функции или стиль теста.

### unknowns

- Согласуется ли ожидаемое поведение из задачи с контрактом целевого проекта.
- Фактический import и сигнатура `normalize_coupon`.
- Содержимое и стиль существующего test-файла.
- Подтверждённый способ проверки.

### redactions

- Полная выгрузка репозитория исключена как не относящаяся к одному решению.
- Секреты и персональные данные не собирались, потому что для решения они не нужны.

**Результат применения пакета (не поле context packet):**

- Артефакт подготовлен: нет.
- Статус задачи: `BLOCKED` до получения product contract, production interface и существующего test-файла с provenance.
- Статус выполнения: `NOT_RUN`.

Наличие всех required-полей делает форму полной, но не превращает недостаточный контекст в достаточный.

## Пакет B — форма полная, контекст достаточен для записи

### task

#### objective

Добавить в режиме `existing` unit-тест поведения `normalize_coupon("   ") -> None` и сохранить его в `tests/unit/test_coupon_normalization.py`, не меняя production-код.

#### mode

`existing`

### sources

| path | kind | freshness | provenance |
|---|---|---|---|
| `task-contract.md` | контракт задачи | текущая задача | решение владельца |
| `specs/coupons.md` | спецификация | подтверждена владельцем для задачи | целевой репозиторий |
| `src/coupons/normalization.py` | production source | текущая рабочая копия | целевой репозиторий |
| `tests/unit/test_coupon_normalization.py` | существующий тест | текущая рабочая копия | целевой репозиторий |

### facts

- `task-contract.md` задаёт тот же objective, разрешает запись только в `tests/unit/test_coupon_normalization.py`, исключает production-код и не разрешает исполнение.
- `specs/coupons.md` подтверждает: строка только из пробелов считается отсутствующим купоном, ожидаемый результат — `None`.
- `src/coupons/normalization.py` экспортирует `normalize_coupon(value)`.
- Существующий test-файл уже импортирует `normalize_coupon` напрямую и именует сценарии по поведению.

### inferences

- Минимальное изменение — один сценарий в существующем unit-файле.
- Общий helper не нужен: повторяемой механической подготовки нет.

### unknowns

- Подтверждённый способ исполнения не предоставлен.
- Фактический результат теста неизвестен до отдельной проверки.

### redactions

- Полная выгрузка репозитория исключена как не относящаяся к одному решению.
- Секреты и персональные данные не включались, потому что для сценария они не нужны.

**Результат применения пакета (не поле context packet):**

В разрешённом пути сохраняется тест:

```python
def test_blank_coupon_is_treated_as_missing() -> None:
    assert normalize_coupon("   ") is None
```

- Артефакт подготовлен: да; показаны сохраняемый путь и содержимое.
- Статус выполнения: `NOT_RUN`.
- Поведение целевой системы: `UNKNOWN`.

## Разница пакетов

| Критерий | Пакет A | Пакет B |
|---|---|---|
| `task.objective` и `task.mode` | Идентичны Packet B | Идентичны Packet A |
| Required-секции | Все присутствуют | Все присутствуют |
| Источники и provenance | Контракт задачи плюс неподтверждённая заметка | Контракт задачи, спецификация, source и существующий тест |
| Факты и выводы | Разделены, но фактов для безопасного кода недостаточно | Разделены и достаточны для ограниченной записи |
| Безопасное действие | Остановиться с `BLOCKED` | Сохранить один тест в существующем файле |
| Выполнение | `NOT_RUN` | `NOT_RUN` |
