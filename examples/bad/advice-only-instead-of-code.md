# Отклонённый пример: совет вместо сохранённого теста

## Задача на реализацию

> Режим `existing`. Добавить unit-тест округления налога. Write-authority для `tests/unit/test_tax_rounding.py` выдана.

## Отклонённый артефакт

```text
Рекомендую добавить тест на округление вверх и проверить граничные значения.
Можно использовать табличный набор и сравнить результат с ожидаемой суммой.
```

Изменённые пути: отсутствуют.

## Нарушенный стандарт

- `QAEF.md`, раздел «Требование реальной записи»: при write-authority результатом должен быть сохранённый тест или разрешённый test-support.
- `standards/prompt-quality.md`, обязательное свойство результата: совет или несохранённый фрагмент не выполняет задачу на реализацию.

## Почему артефакт отклонён

Ответ описывает возможный следующий шаг, но не создаёт наблюдаемый результат. Нельзя проверить, какой oracle выбран, какой путь затронут и соответствует ли код стилю проекта. Намерение автора не заменяет сохранённый тест.

## Исправленная форма

Из задачи подтверждены только режим, write-scope и требование получить unit-тест. Product oracle, production interface и существующий стиль не предоставлены, поэтому безопасная correction не придумывает код.

```text
Разрешённый будущий путь: tests/unit/test_tax_rounding.py
Изменённые пути: отсутствуют
Артефакт подготовлен: нет
Статус задачи: BLOCKED
Статус выполнения: NOT_RUN
Поведение целевой системы: UNKNOWN
```

Для продолжения нужны источники с provenance:

- правило округления и ожидаемые значения на границах;
- production source с фактическим import, сигнатурой и типами;
- текущий unit-файл или принятый проектный пример стиля.

После получения этих источников результатом должен стать сохранённый тест в разрешённом пути. До этого совет, snippet и уверенный oracle одинаково недопустимы.
